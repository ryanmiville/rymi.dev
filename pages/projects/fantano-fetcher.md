A small web app for exploring Anthony Fantano’s album reviews, fetched from his YouTube channel.

## Behind the app

Built with Next.js and React server components, with Drizzle and Turso for the review data. The interface uses shadcn/ui and Tailwind CSS.

The repository includes a SQLite database for local development. That development copy is a snapshot, rather than an up-to-date review feed.
